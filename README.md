# AI-Powered Resume & Job Matcher

## Overview

This project is a beginner-friendly application that helps job seekers understand how well their resume matches a specific job description. You upload your resume and paste in a job description, and the app compares the two to show you how good the match is and what you could improve.

## Main Goal

The main goal of this application is to help users quickly see how well their resume fits a job posting by identifying matching skills, missing skills, and giving suggestions on how to improve their resume for that specific job.

## Planned Technologies

- Java 21
- Spring Boot
- MySQL
- OCI Generative AI
- React
- TypeScript
- Maven
- Docker
- GitHub Actions

## Planned Workflow

1. Upload a resume
2. Enter a job description
3. Extract skills from both the resume and the job description
4. Calculate a compatibility score
5. Display matched skills
6. Display missing skills
7. Show improvement suggestions

## Project Status

This project is currently in development. Features and structure are subject to change.
